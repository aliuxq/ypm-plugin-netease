# 网易云音乐 for YesPlayMusic

[English](./README.en.md) · 简体中文

[YesPlayMusic](https://github.com/qier222/YesPlayMusic) 3.0 的**第三方**网易云音乐音乐源插件。YesPlayMusic 3.0 本身不带任何在线音乐服务，装上这个插件后可以扫码登录网易云账号，继续使用你的歌单、红心歌曲、收藏专辑、每日推荐和私人 FM。

> 这不是官方插件，与网易公司、YesPlayMusic 作者均无关联。

## 功能

- **首页**：每日推荐、私人 FM、推荐歌单、新歌速递、新碟上架、排行榜
- **发现**：按分类浏览歌单、全部排行榜、我的云盘
- **搜索**：单曲、专辑、歌手、歌单，搜索联想和热搜
- **音乐库**：我喜欢的音乐、收藏的专辑、关注歌手、最近播放、累计听歌
- **歌单**：创建、重命名、删除，加歌、删歌，收藏别人的歌单
- **专辑 / 歌手页**：收藏专辑、关注歌手，歌手的热门歌曲、全部专辑和相似歌手
- **播放**：标准 / 高音质 / 无损 / Hi-Res 四档音质（自动降级），歌词与翻译，相似歌曲，私人 FM
- **评论**：热门和最新评论，发评论、回复、点赞
- **个人主页**：等级、关注与粉丝、累计听歌、最近一周最常听
- 播放后自动上报听歌记录
- 界面文案支持简体中文、繁体中文和英文

## 安装

1. 打开 YesPlayMusic（需 **3.0.0 或更高版本**）→ **设置 → 插件 → 安装插件**，粘贴：

   ```
   github.com/aliuxq/ypm-plugin-netease
   ```

2. 安装前应用会列出插件要的权限和提供的功能，确认后点「安装」。
3. 右键左下角头像（或在 **设置 → 插件 → 音乐来源** 里）切换到「网易云音乐」。

也可以下载 [Release](https://github.com/aliuxq/ypm-plugin-netease/releases) 里的 zip，解压后用「从本地文件夹安装…」。

## 登录

点左下角头像 → 登录，用网易云音乐 App 扫码并在手机上确认。

如果扫码被网易云的风控拦截：在浏览器登录 [music.163.com](https://music.163.com/)，按 F12 → Application → Cookies，复制 `MUSIC_U` 的值，粘贴到 **设置 → 插件 → 网易云音乐 → 插件设置** 的 Cookie 一栏，再点一次登录。填了 Cookie 就优先使用它。

登录状态只保存在本机插件数据目录（`plugin-data/netease/`）里，除了发给网易云自己的服务器，不会发到别处。

## 权限

| 权限 | 用途 |
| --- | --- |
| 网络：`interface.music.163.com` | 网易云音乐客户端接口。插件只访问这一个主机。 |

插件不启动本机程序，不读写插件目录以外的文件。封面图和音频由 YesPlayMusic 自己从网易云的 CDN 下载。

## 已知限制

- **不解锁任何内容**。没有版权（灰色）的歌、要单独购买的数字专辑放不了；VIP 歌曲需要账号本身是会员。只能试听片段的歌会直接标成不可播放，不会用试听冒充完整歌曲。
- 歌手页的专辑接口较慢，专辑特别多的歌手要等几秒（最多显示 100 张）。
- YesPlayMusic 的歌单拖动排序（`movePlaylistTrack`）、播客、逐字歌词没有实现。
- 网易云的接口不是公开接口，随时可能变化或加强风控，届时插件可能失效。

### 关于卡顿与无响应

以下卡顿 / 无响应现象源于 YesPlayMusic 应用本身的图片渲染瓶颈与崩溃缺陷，**并非本插件造成**，特此说明：

- **点入「艺人」页面出现卡顿属于正常现象**：艺人页需一次性加载大量封面图，应用渲染时会有明显卡顿；
- 本插件通过精简请求与数据，**仅能在部分情况下避免超时报错**，无法根治应用层的渲染卡顿；
- 当**收藏歌曲较多**时，点入「歌单」「专辑」等页面，软件仍可能出现**短暂无响应**；
- 点入「歌单」「专辑」页面同样会比较卡。

### 关于封面图分辨率

作者曾尝试降低封面图分辨率以缓解加载压力，但实测发现，**降低分辨率会明显影响歌曲、歌词页面的封面观赏体验**，因此**放弃该项优化**，保持原有分辨率。

## 开发

```
index.js          插件本体：导出的函数名就是应用调用的操作名
plugin.json       清单：权限、设置项、侧边栏
client.js         eapi 客户端：请求加密、会话管理
models.js         网易云数据 → 插件数据结构的转换
i18n.js           host.t 的封装（支持 {占位符} 插值）
locales/          界面文案翻译
test/             在 Node 里模拟应用的 host 环境来跑插件
```

不需要构建。改完代码后把文件放进应用的插件目录，在 **设置 → 插件** 里点「重新加载」。

```bash
node test/harness.mjs                       # 列出插件导出的函数
node test/harness.mjs search '{"query":"海屿你"}'
node test/harness.mjs playlist '{"id":"3778678"}'
```

### 实现说明

- 请求走网易云 PC 客户端的 eapi 接口，加密用应用提供的 `host.crypto`（MD5 + AES-128-ECB），不带任何第三方库，也不需要自己实现 RSA。
- 网易云用 id `0` 表示「没有这个歌手 / 专辑」，插件把它转成空串，避免生成打不开的链接。
- `savedAlbums` 必须返回纯数组（宿主 3.0.0 的音乐库页把它直接当数组用）。
